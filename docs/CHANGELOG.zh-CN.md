# 更新说明

## 0.9.2 · 2026-09-11

本版修复科研工作台审核中发现的稿件身份、任务状态和材料扫描问题。升级后请重启 DSH 并刷新浏览器，确保宿主和客户端同时更新。

- **稿件核验**：接受审稿阶段结果及启动后续任务前，由宿主核对原稿、新稿是否存在于当前工作区。不同路径写法、Windows 大小写和硬链接不能冒充独立新稿；返回的原稿必须与用户明确指定的文件一致。
- **闭环恢复**：异步保存期间到达的回复会继续处理；首条助手回复前的模型失败会停止等待，历史错误不会直接冒充新任务错误。暂停、跨项目切换和后续人工消息继续撤销自动衔接。
- **普通任务回流**：先保存待检查状态，再扫描产物，修复保存较慢时任务一直卡在“正在检查产物”的问题。
- **材料扫描**：先应用论文子目录和排除规则，再遍历并计数；无关目录不再挤占指定子目录的扫描额度。范围配置保存后自动重扫。
- **扫描失败显示**：同工作区重新扫描期间及失败后保留上次材料清单；另一工作区不会显示该缓存。
- **命令可用性**：保留 4 个核心技能，注册 13 个可用命令。`ars-mark-read`、`ars-unmark-read`、`ars-cache-invalidate` 依赖未移植的上游 Python 工具与契约，暂不注册；原定义保留用于署名与后续移植。技能入口增加 DSH 能力与缺失依赖说明，禁止将缺失的检查描述成已通过。
- **回归检查**：增加真实 React 异步测试、真实文件系统身份测试，以及 Windows/macOS/Linux、Node.js 20/22 的 GitHub Actions 检查。

稿件身份核验是只读检查，尚不包含写前备份、文件内容哈希或确定性稿件差异审查。模型报告的修改与学术判断仍需作者核验。

更新命令（先等待当前任务结束并停止 DSH）：

```bash
dsh plugin --profile web add github:masskx/dsh-research-loom --force
dsh web
```

刷新浏览器后可按 [验证说明](QA.zh-CN.md) 检查材料刷新、失败恢复与审稿闭环。
