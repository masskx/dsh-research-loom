# 更新说明

## 0.10.0 · 2026-09-11

针对第一次返修时需要反复组织材料、手写范围、处理中断的问题，新增连续的材料确认与返修任务体验。

- 选择并保存本轮主稿、原始意见文件、轮次和版本对应关系。支持“不知道”和历史意见；更换选择或排除已选材料会撤销确认。
- 从原始意见文件直接启动结构化清单，不必先选一条模型诊断。意见卡保留原文来源、解释、适用性、缺失证据和完成条件；来源提取仍需核验。
- 勾选具体文字任务，最多 20 项；默认先推荐选择一项。未选问题不得被模型推进完成状态，实验和作者决策继续保留。
- 新增中断后已有修订稿的只读恢复，保留已接受的问题清单，不补造修改成功记录；支持重试失败的只读复核。
- 新增宿主只读文本差异查看及当前 SHA-256，限制文件大小和预览长度；不支持的格式、截断和边界明确显示。
- 导出可读的返修检查清单与回复填写模板，保留状态、原意见、来源和待办。
- 兼容旧闭环记录及通用提示词入口；新增字段通过宿主设置保存，项目迁移不携带自动执行权限。

本版不含写前快照、Word/PDF 内容差异、LaTeX 编译或实验真实性验证。使用与边界见 [第一次返修指南](NOVICE-REVISION.zh-CN.md)。

## 0.9.3 · 2026-09-11

实际论文交接项目同时包含大量代码、稿件和历史审稿材料。新手入口原先按路径取前 60 项，排序靠前的代码可能占满名额，导致主稿和意见缺席。

- 按当前任务优先抽取相关材料类型，并在类型间分配候选位置；手动归类的文件优先，不能被材料面板的单类型展示上限隐藏。
- 提示词注明已扫描候选数、展示数和版本歧义，抽样不等于识别出了权威稿件。目录排除和 60 项上限继续生效。
- 增加代码较多、多稿件版本、手动归类与排除目录的中英文回归用例。
- 修正安装指南的旧版本号。真实项目使用步骤见 [论文交接项目试用](HANDOFF-TRIAL.zh-CN.md)。

写前备份、真实文件差异和排版检查仍由外部验证完成，未随本次修复变成插件内置功能。

## 0.9.2 · 2026-09-11

本版修复科研工作台审核中发现的稿件身份、任务状态和材料扫描问题。升级后请重启 DSH 并刷新浏览器，确保宿主和客户端同时更新。

- **稿件核验**：接受审稿阶段结果及启动后续任务前，由宿主核对原稿、新稿是否存在于当前工作区。不同路径写法、Windows 大小写和硬链接不能冒充独立新稿；返回的原稿必须与用户明确指定的文件一致。
- **闭环恢复**：异步保存期间到达的回复会继续处理；首条助手回复前的模型失败会停止等待，历史错误不会直接冒充新任务错误。暂停、跨项目切换和后续人工消息继续撤销自动衔接。
- **普通任务回流**：先保存待检查状态，再扫描产物，修复保存较慢时任务一直卡在“正在检查产物”的问题。
- **材料扫描**：先应用论文子目录和排除规则，再遍历并计数；无关目录不再挤占指定子目录的扫描额度。范围配置保存后自动重扫。
- **扫描失败显示**：同工作区重新扫描期间及失败后保留上次材料清单；另一工作区不会显示该缓存。
- **命令可用性**：保留 4 个核心技能，注册 13 个可用命令。`ars-mark-read`、`ars-unmark-read`、`ars-cache-invalidate` 依赖未移植的上游 Python 工具与契约，暂不注册；原定义保留用于署名与后续移植。技能入口增加 DSH 能力与缺失依赖说明，禁止将缺失的检查描述成已通过。
- **回归检查**：增加真实 React 异步测试、真实文件系统身份测试，以及 Windows/macOS/Linux、Node.js 20/22 的 GitHub Actions 检查。

稿件身份核验是只读检查，尚不包含写前备份、文件内容哈希或确定性稿件差异审查。模型报告的修改与学术判断仍需作者核验。

更新命令（先等待当前任务结束并停止 DSH）：

```bash
dsh plugin --profile web add github:masskx/dsh-research-loom --force
dsh web
```

刷新浏览器后可按 [验证说明](QA.zh-CN.md) 检查材料刷新、失败恢复与审稿闭环。
